# 손결 공방 (포트폴리오 데모)

도자기 원데이 클래스 예약·결제 사이트 데모입니다. 실제 공방이 아니며, 결제는 토스페이먼츠 **테스트 모드** 또는 시뮬레이션으로만 동작합니다.

## 사용자 흐름
1. 클래스 선택 → 날짜·시간·인원 선택 (회차별 잔여석 표시, 마감 회차 비활성)
2. 예약자 정보 입력 → 결제
3. 예약 확정 화면에서 **예약 코드** 발급
4. 예약 조회(코드 + 휴대폰 번호) → 시작 24시간 전까지 직접 취소 시 자동 전액 환불

## 결제 구현 포인트
- **결제 금액은 서버에서 계산**하고, 승인 전에 저장된 주문 금액과 결제 요청 금액이 같은지 검증합니다 (클라이언트 금액 조작 방지).
- 주문 생성 시 좌석을 **10분간 홀드**합니다. 같은 회차에 동시에 예약해도 정원을 넘지 않도록 회차별 잠금으로 처리합니다 (Supabase는 DB 함수 + advisory lock).
- 승인·취소는 상태 전이(`pending → paid → cancelled`)로만 처리하여 **중복 승인·중복 환불을 막고**, 결제 완료 페이지를 새로고침해도 안전합니다.
- 토스 API 호출에 `Idempotency-Key`를 사용합니다.
- 결제창을 닫은 경우 좌석 홀드를 유지해 10분 안에 다시 시도할 수 있습니다.

## 관리자 (`/admin`)
- 비밀번호 로그인 (데모: `demo1234`)
- 대시보드: 이번 달 결제액, 예정 예약, 오늘 회차 좌석 현황
- 예약·결제 목록: 상태별 탭, 이름·번호·예약코드 검색
- 예약 상세: 결제 정보, 처리 이력, **결제 취소·환불**
- 회차 현황: 앞으로 7일간 회차별 예약 인원

## 환경변수
| 이름 | 설명 |
| --- | --- |
| `NEXT_PUBLIC_TOSS_CLIENT_KEY` | 토스페이먼츠 **API 개별 연동** 테스트 클라이언트 키 (`test_ck_...`) |
| `TOSS_SECRET_KEY` | 토스페이먼츠 테스트 시크릿 키 (`test_sk_...`) |
| `SUPABASE_URL` / `SUPABASE_SERVICE_ROLE_KEY` | 예약 데이터 저장 (없으면 메모리 데모 저장소) |
| `ADMIN_PASSWORD` | 관리자 비밀번호 (기본 `demo1234`) |
| `ADMIN_DEMO_MODE` | `false`면 로그인 화면의 데모 비밀번호 안내 숨김 |
| `SESSION_SECRET` | 관리자 세션 서명 키 (32자 이상) |

- 토스 키가 **없으면** 결제가 시뮬레이션으로 처리됩니다 (화면 상단에 안내 표시).
- 토스 키는 [개발자센터](https://developers.tosspayments.com) 가입 후 API 키 메뉴에서 무료로 발급됩니다 (계약 불필요). 테스트 키로는 실제 결제가 일어나지 않습니다.
- Supabase를 쓰려면 SQL Editor에서 `supabase/setup.sql`을 실행하세요.

## 실행
```bash
npm install
npm run dev
```
